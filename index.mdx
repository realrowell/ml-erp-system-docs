ML ERP is an internal operations platform for businesses that own and service vending machines ("Vendos"). It brings customers, contracts, field collections, asset health, support tickets, and finances into a single Laravel + Vue application so admins, technicians, and collectors can run day-to-day operations from one place.

## Who it's for

- **Admins** managing customers, contracts, finances, and staff.
- **Technicians** servicing Vendos in the field and responding to support tickets.
- **Collectors** running scheduled collection periods and reconciling cash against contracts.

## Tech stack

- Laravel 12 on PHP 8.4 with Inertia.js v2
- Vue 3 + TypeScript + Tailwind CSS v4
- Laravel Fortify (auth + 2FA), Sanctum, Wayfinder
- SQLite by default for local development; swap to MySQL/PostgreSQL via `.env`
- PDF export via `barryvdh/laravel-dompdf`; QR codes via `bacon/bacon-qr-code`
